Configure the SQS event source mapping with `ReportBatchItemFailures`. The handler expects S3 keys in `originals/{userId}/{photoId}.{extension}` form and a pre-created DynamoDB photo item keyed by `photoId`. It generates deterministic WebP objects under `thumbnails/` and `medium/` in `PROCESSED_BUCKET`, then conditionally updates `PHOTOS_TABLE`. Creating the PENDING item before issuing the presigned URL is therefore required. Duplicate events overwrite the same rendition keys. Build/package Pillow for Lambda Python 3.14 and the selected architecture; use a Lambda-compatible container for native wheels.
