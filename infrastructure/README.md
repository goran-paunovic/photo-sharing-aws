# CDK notes
This is an infrastructure baseline, not yet a deploy-ready stack. ECS desired count is 0 so an API image must be pushed and desired count configured before use. ALB is HTTP-only behind CloudFront; production should use HTTPS origin and security group restrictions so ALB cannot be bypassed. The VPC has no NAT Gateway; private egress and AWS service access need endpoints or a reviewed egress design. Finish Cognito hosted UI callback URLs, CloudFront signed viewer access, alarms, WAF, TLS custom domain, DNS, and retention policies. Review the generated templates and IAM grants before deployment.
